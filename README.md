# Sleep, Screen Time and Stress Analysis

## Project Overview

This project explores the relationship between smartphone usage, sleep patterns, lifestyle habits, and stress levels.

The dataset contains 15,000 synthetic records representing individuals with different lifestyles, occupations, and smartphone usage habits.

The primary goal is to investigate behavioral patterns, discover meaningful relationships, perform statistical analysis, and eventually build machine learning models.

---

## 1. Project Objectives

The project is divided into four major parts:

| Phase | Objective |
|---|---|
| 1. Exploratory Data Analysis | Understand distributions, missing values, outliers, and patterns. |
| 2. Statistical Analysis | Investigate relationships between screen time, sleep, and stress. |
| 3. Feature Engineering | Create meaningful features from existing variables. |
| 4. Machine Learning | Build models to predict stress levels or sleep quality. |

---

## 2. Research Questions

Rather than creating visualizations randomly, this project follows specific research questions.

### A. Screen Time and Sleep

- Does higher daily screen time correspond to shorter sleep duration?
- Does using a smartphone before bedtime relate to poor sleep quality?
- Is nighttime phone usage more important than total daily screen time?

### B. Lifestyle and Stress

- Does caffeine consumption relate to higher stress levels?
- Does physical activity correspond to lower stress?
- Which lifestyle factors are most strongly associated with stress?

### C. Combined Analysis

- Do people with high screen time and low physical activity experience higher stress?
- Does sleep quality help explain the relationship between screen time and stress?

## 3. Project Workflow

### Phase 1: Data Understanding
- Understand dataset shape.
- Examine column names and data types.
- Identify target variables.
- Understand the data dictionary and feature meanings.

### Phase 2: Data Quality Assessment
- Check missing values.
- Identify duplicate records.
- Examine inconsistent values.
- Detect potential outliers.
- Validate data ranges and constraints.

### Phase 3: Univariate Analysis
- Understand individual feature distributions.
- Analyze categorical and numerical variables.
- Identify skewness and unusual patterns.

### Phase 4: Bivariate and Multivariate Analysis
- Explore relationships between screen time and sleep.
- Investigate lifestyle factors and stress.
- Analyze interactions between multiple variables.
- Use appropriate visualizations and correlation analysis.

### Phase 5: Statistical Hypothesis Testing
- Formulate null and alternative hypotheses.
- Select appropriate statistical tests.
- Evaluate statistical significance.
- Interpret p-values and confidence intervals.
- Distinguish statistical significance from practical significance.

### Phase 6: Feature Engineering and Machine Learning
- Create meaningful features.
- Prepare preprocessing pipelines.
- Establish baseline models.
- Train and evaluate machine learning models.
- Compare model performance using appropriate metrics.

### Phase 7: Conclusion and Storytelling
- Summarize important findings.
- Answer the original research questions.
- Present meaningful visualizations.
- Discuss limitations.
- Prepare a final project report.

---

## 4. Important Consideration

**Dataset limitation:** This dataset contains synthetic records. Therefore, discovered relationships should not be interpreted as established real-world health effects.

The analysis will focus on understanding the dataset, statistical relationships, analytical techniques, and machine learning methodologies.
